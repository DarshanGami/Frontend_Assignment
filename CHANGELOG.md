# Changelog

## [1.0.0] - 2025-11-25

### Added
- Initial release of Quiz Application
- Next.js 14 with App Router
- TypeScript with strict mode
- Tailwind CSS with custom theme
- Framer Motion animations
- 4 quiz questions with multiple choice answers
- Progress tracking (1/4, 2/4, 3/4, 4/4)
- Score calculation and display
- "Best of Luck!" mascot on first question
- Navigation between questions
- Submit quiz functionality
- Results page with percentage score
- "Start Again" functionality
- Full WCAG 2.1 accessibility compliance
- Responsive desktop layout
- Unit tests for quiz logic
- ESLint and Prettier configuration
- Comprehensive documentation

- ✨ Pixel-perfect design matching Figma screenshots
